# Profile artwork

Original, code-drawn pixel-art AI research workstation. The scene depicts source
passages, a trace-review terminal and a small evidence archive. It is decorative;
its screens are not screenshots, scores or claims about a deployed system.

Regenerate with `python3 scripts/build_visuals.py` from the repo root. Requires
Pillow 10.1 or newer. The script uses installed DIN Condensed/Menlo fonts on macOS,
with DejaVu fallbacks on Linux; no font files are redistributed.

The GIF has a slow cursor/status-light change. The profile uses the PNG when the
browser requests reduced motion. Both files are self-hosted in this repository;
there are no external statistics cards, counters or image-generation services.

The current `ai-workspace` banner leaves personal identification to GitHub's
sidebar. Matching SVG project panels and section headers carry the AI-game
interface across the complete README. Their trace diagrams are illustrative,
not measurements. Descriptions, citations, validation caveats and links remain
native selectable text. The older `ai-research-lab` pair is retained as artwork
history and is not used by the current profile.
